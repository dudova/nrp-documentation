# 1. Planning
## Data Producer responsibilities
- Identification of the data source (project, study, data collection) and stakeholders
- Selection of an appropriate repository (community fit, policies, capabilities)
- Metadata scoping, including identification of sensitive/controlled metadata
- Data Management Plan (DMP) for sensitive data:
  - Roles and responsibilities; stewarding arrangements
  - Risk model (Risk = Threat × Exposure × Impact)
  - Storage class, retention, backup, transfer, deletion, and organisation of data/metadata
  - Ethical–legal requirements (GDPR, IP, EHDS, DGA/DA) and legal basis
  - Statistical Analysis Plan (SAP) outline and versioning strategy
  - Reproducibility plan (workflow engines, containers, notebooks)
- Technical planning:
  - Preferred compute model (TRE/secure VDI vs batch/containers)
  - Data formats, open standards, and prevention of vendor lock‑in

# 2. Collection
## Data Producer responsibilities
- Automated and manual data collection workflows; instrument integrations; ELNs
- Data and metadata capture according to profiles; provenance capture at source
- Primary validation (format, completeness, basic consistency)
- Documentation of consent, ethics approvals, and deviations from protocol
- Application of de‑identification/minimisation where appropriate

# 3. Processing
## Data Producer responsibilities
- Data cleaning, transformation, standardisation; QA/QC gates
- Semantic annotation (ontologies, taxonomies, controlled vocabularies)
- Linking to external authorities (e.g., ORCID, PubMed; sample registries)
- Execution environments (secure VDI/TRE, batch, containerised workflows)
- Documentation of processing steps and parameters for reproducibility

# 4. Analysis
## Data Producer responsibilities
- Generation of analytical outputs and derived datasets
- Full methodological transparency (protocols, code, notebooks, parameters)
- Repeatability checks; internal peer validation; result–data linkage

# 5. Preservation
## Data Producer responsibilities
- Preparation of deposit packages (AIPs/SIPs), checksums, and submission manifests
- Selection of preservation formats; assignment of licences and access conditions

# 6. Sharing / Publication
## Data Producer responsibilities
- Setting access permissions (open, embargoed, restricted; purpose‑based access)
- Publication in the user interface with human‑readable summaries and README
- Compilation of legal artefacts (DUA, DTA, data access policies)

# 7. Reuse
## Data Producer responsibilities
- Community engagement (usage notes, known limitations, contact points)
- Responding to data access requests and clarifications

# 8. Cross‑Cutting Controls and Enablers
- Security standards and controls (ISO 27001 aligned; risk‑based controls; logging)
- Ethics and legal compliance (GDPR/IP/EHDS/DGA/DA) and governance
- AAI and policy models (authentication, authorisation, purpose limitation)
- Provenance, identifiers, and metadata quality management
- QA/QC framework (entry checks, curation checks, publication checks)
- Vendor lock‑in avoidance and data portability (open formats, APIs, export)

- Repository‑specific policies and submission guidelines
