# Planning

## Responsibilities of the Data Producer

- Identify the data source (project, study, collection) and stakeholders.
- Select an appropriate repository based on scope, policies and capabilities.
- Define the scope of metadata, including identification of sensitive or controlled attributes.
- Prepare a Data Management Plan (DMP) for sensitive data, covering:
  - Roles and stewarding responsibilities
  - Risk model (Risk = Threat × Exposure × Impact)
  - Storage, retention, backup, transfer and deletion
  - Ethical and legal requirements (GDPR, IP, EHDS, DGA/DA)
  - Statistical Analysis Plan (SAP) and versioning strategy
  - Reproducibility plan (workflows, containers, notebooks)
- Plan technical aspects:
  - Compute model (TRE / secure VDI vs batch or containers)
  - Data formats and open standards
  - Vendor lock-in avoidance

## Responsibilities of the Repository

- Clearly communicate repository scope, policies and eligibility criteria.
- Provide guidance on supported metadata profiles and controlled vocabularies.
- Define supported storage classes, access models and retention policies.
- Specify legal, ethical and security requirements applicable to sensitive data.
- Provide templates or references for DMPs, consent language and access conditions.
- Clarify available execution environments (e.g. TRE, secure compute) if applicable.

## Practical notes and expectations

Planning is iterative. Early contact with the repository helps prevent later rework or rejection.
