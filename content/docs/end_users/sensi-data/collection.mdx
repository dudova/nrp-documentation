# Collection

## Responsibilities of the Data Producer

- Implement automated or manual data collection workflows.
- Capture data and metadata according to agreed profiles.
- Record provenance at the point of collection.
- Perform primary validation (format, completeness, basic consistency).
- Document consent, ethics approvals and deviations from protocol.
- Apply de-identification or minimisation where appropriate.

## Responsibilities of the Repository

- Provide guidance on acceptable data formats and metadata capture.
- Define minimum validation and documentation requirements.
- Specify how consent and ethics documentation must be provided or referenced.
- Clarify expectations for de-identification prior to ingest.

## Practical notes and expectations

Incomplete metadata or missing consent documentation are common causes of ingest delays.
